2. أزرار (قبول / اشتراك / إيقاف / إلغاء جهاز) كانت ميتة لأن الـ CSP بيمنع `onclick` الداخلي.
3. زر "اشتراك شهر / مدى الحياة" كان بيرجع خطأ Postgres `42P08` (نوع البارامتر `$2`) فمفيش ترخيص بيتعمل.

## الجديد
- مستخدم جديد يسجّل ← يسجّل دخول ← تفتحله صفحة: اختيار باقة (250 / 2000 / 3000) + رقم فودافون كاش + رفع سكرين التحويل.
- في الأدمن: تبويب **طلبات الدفع** (عرض الإيصال، قبول وتفعيل، رفض بسبب). القبول بيقبل الحساب + يفعّل الترخيص + يسجّل الدفعة تلقائي.
- **رقم فودافون كاش**: من الأدمن ← إعدادات النشر ← "رقم فودافون كاش" (أو متغير `VODAFONE_CASH_NUMBER`). من غير رقم صفحة الدفع بتعرض تنبيه.
- لينك فيسبوك في البرنامج والداشبورد.
- `NASAQ-Studio.vbs` يفتح البرنامج من غير cmd. والأفضل: ابني النسخة النهائية `.exe` (GitHub Actions: Run workflow) فتبقى برنامج عادي.

## الرفع (إضافات فقط، مفيش مسح بيانات)
ارفع ملفات `license-server/`: `server.js` (سطر واحد مضاف + إصلاح cast)، `nasaq-payments.js` (جديد)، `public/index.html`، `Dockerfile`، وبعدين ملفات البرنامج: `main.js`, `preload.js`, `package.json`, `renderer/*`. الجداول الجديدة (`payment_requests`, `app_settings`) بتتعمل تلقائي بـ IF NOT EXISTS؛ لو يوزر الداتابيز ممنوع CREATE شغّل `migrations/002_payments.sql`.
نقطة مهمة: لو عندك تعديلات في `server.js` على Vercel مش في الملف ده، ادمج بس السطر `require('./nasaq-payments')(app, pool);` قبل `app.use(express.json(...))` وتعديل `$2::varchar`.
