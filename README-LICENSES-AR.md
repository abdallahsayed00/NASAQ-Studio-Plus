# NASAQ Studio+ v1.2.0 — نظام الحسابات والتراخيص

هذا الإصدار يضيف شاشة تسجيل/إنشاء حساب داخل التطبيق، ويتطلب موافقة الإدارة وترخيصًا نشطًا قبل فتح أدوات البلاجن. كما يحتوي المشروع على API منفصل ولوحة إدارة عربية/إنجليزية وقاعدة بيانات PostgreSQL.

## مهم قبل التشغيل

لا يوجد خادم مستضاف أو دومين أو قاعدة بيانات متصلة حتى الآن لأن بيانات الاستضافة لم تُقدّم. لذلك لن يعمل تسجيل الدخول العام حتى تنشر الخادم وتضبط عنوانه في ملف إعدادات التطبيق.

## النشر المختصر

1. افتح `DEPLOYMENT-LICENSES.md` واتبع خطوات تجهيز PostgreSQL ونشر `license-server/` على استضافة Node.js مع HTTPS.
2. نفّذ `license-server/migrations/001_init.sql` على قاعدة البيانات.
3. أنشئ أول مسؤول بالأمر الموضح في دليل النشر؛ لا يوجد حساب مسؤول افتراضي.
4. افتح لوحة الإدارة على دومين الخادم وسجّل الدخول.
5. أنشئ الملف `%APPDATA%\nasaq-studio\license-config.json` على جهاز المستخدم وضع فيه عنوان API الحقيقي بصيغة HTTPS. يوجد مثال في `license-config.example.json`.
6. أعد تشغيل التطبيق. التسجيل الجديد يكون Pending حتى تقبله، ثم سجّل الدفع يدويًا وأنشئ اشتراكًا أو ترخيص مدى الحياة.

## الاختبارات

- `node --check` لملفات JavaScript الخاصة بالتطبيق والخادم: ناجح.
- `node test/jsx-test.js`: 15 اختبارًا ناجحًا للوظائف الحالية.
- اختبار المتصفح Playwright لم يكتمل لأن Chromium غير مثبت في بيئة البناء.
- لم يتم اختبار اتصال حي بقاعدة بيانات أو استضافة أو Photoshop/Windows من بيئة البناء هذه.

اقرأ قسم «القيود قبل الإطلاق التجاري» في `DEPLOYMENT-LICENSES.md`. لا تعتبر المشروع منشورًا أو مختبرًا أمنيًا بالكامل قبل إعداد الخدمات واختبارها على بيئة Staging.
